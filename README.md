# Hi, TracByte Here!

Welcome to our repository! This is where I keep all of my **Windows Winget Command Text Files** for quick software installations, updates, and removals.

### How to Use & Contribute

Anyone who wants to build on this or contribute can do so anytime! However, to save time, **I won't be accepting or merging any Pull Requests on this repository.**

Instead, if you want to add features, fix bugs, or build your own version:

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork and code away!
3. **Build, change, and share** your version as much as you like.

Feel free to `git clone` the repo to check out the commands on your own machine. 

Don't forget to share this and follow [**tracbyte**](https://github.com/tracbyte/tracbyte#-connect-with-me) on all platforms!
